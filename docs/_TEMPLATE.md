# action 文档模板

> 复制本文件为 `docs/<action 名>.md` 后逐节填写。**`## 常见错误` 是必填项**——字段表在百度官方文档也有，只有踩过的坑才是本 skill 的增量价值。

## 章节清单（按此顺序）

| 章节 | 是否必填 | 说明 |
|---|---|---|
| `# <中文名>` | 必填 | 与 SKILL.md action 表里的能力描述保持一致 |
| `## Trigger` | 必填 | 用户会怎么说才触发这个 action（写用户原话，不写技术术语） |
| `## Action` | 必填 | 反引号包裹的 action 名 |
| `## 接口` | 必填 | 请求地址 + 方法说明（取自官方文档） |
| `## Payload` | 必填 | 完整可执行的 JSON 示例，`userName` 写真实示例值，**不要写 `{{...}}` 占位符、不要写 accessToken** |
| `## 安全要求` | 写操作用必填 | 会改什么、不可逆性、执行前必须确认的项、是否要求 `confirmWrite` |
| `## 输入字段` | 必填 | 字段 / 类型 / 必填 / 说明 / 限制（限制要写具体数值区间） |
| `## 返回字段` | 必填 | 只列调用方真正会用到的字段 |
| `## 行为说明` | 选填 | 官方语义补充（如"仅适用于绑定到单元层级"） |
| `## 常见错误` | **必填** | 见下方要求 |
| `## 调用示例` | 必填 | 可直接复制的 `node scripts/api.ts --payload='...'` |

## `## 常见错误` 写什么

只写**实测踩过或官方明确警告过的**，每条格式为「现象 → 原因 → 怎么办」：

```markdown
## 常见错误

| 现象 | 原因 | 处理 |
|------|------|------|
| `status=2 code=9015` | 必填字段拼错或缺失 | 对照本文「输入字段」逐个核对 |
| ... | ... | ... |
```

禁止写：泛泛的"参数错误请检查参数"。要写具体的码、具体的字段、具体的数值边界。

## 校验

新增或修改文档后确认：

- action 已出现在 `SKILL.md` 的 action 索引中
- 写操作已注册校验器（未注册会被 `BAIDU_INTERNAL_ERR` 拦住）
- 文档内 JSON 代码块可解析
- 接口地址与官方页一致（比对记录见 `verification-log.md`）
