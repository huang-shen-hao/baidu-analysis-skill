# 官方资料入口

需要核验百度营销 API、百度推广 API 或 oCPC 接入细节时，优先打开这些资料。

## 百度商业开发者中心

- 用户提供入口：https://dev2.baidu.com/content?sceneType=0&pageId=100182&nodeId=13
- OAuth2.0 授权页入口：https://u.baidu.com/oauth/page/index
- 公开说明中提到，百度商业开发者中心官方网站是 `dev2.baidu.com`，用于百度推广 API/商业开放平台相关能力。

## oCPC 开发者文档

- 搜索推广对接流程：https://ocpx.baidu.com/developer/ocpc-doc/api/api-doc/api-fc/
- 信息流推广对接流程：https://ocpx.baidu.com/developer/ocpc-doc/api/api-doc/api-feed/
- 接口文档：https://ocpx.baidu.com/developer/ocpc-doc/api/api-doc/api-interface/
- 数据核对：https://ocpx.baidu.com/developer/ocpc-doc/api/api-faq/transdata.html

## 使用规则

- 接口开发、字段确认、鉴权流程、错误处理、数据核对和转化回传必须以当前打开的官方页面为准。
- 如果官方页面需要登录、无法抓取或内容动态加载，让用户提供截图、导出的文档、接口页面内容或测试账号信息。
- 只把可公开的文档链接和非敏感流程写入参考文件；不要记录客户账号、token、密钥、消费数据或线索数据。
